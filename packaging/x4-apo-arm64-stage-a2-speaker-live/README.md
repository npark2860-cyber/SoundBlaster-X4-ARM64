## Test-signing prerequisite

This is a development test package, not a production-signed driver package.

The runner script deliberately does **not** change Secure Boot or BCD settings.

Before installation, the test machine must already be in a state that accepts test-signed driver packages:

1. Secure Boot disabled;
2. Windows `TESTSIGNING` enabled;
3. reboot completed.

Microsoft documents that enabling `TESTSIGNING` normally requires Secure Boot to be disabled for this development path.

## Install behavior

`Install` performs these operations only after all preflight gates pass:

1. verifies host architecture, X4 MI_03 and `usbaudio2`;
2. verifies the ARM64 DLL and test signatures;
3. imports only the artifact's public test certificate into LocalMachine Root and TrustedPublisher;
4. stages the APO component INF first;
5. installs the X4 Extension INF second;
6. triggers PnP rescan;
7. records exact `oem*.inf` package names and certificate thumbprint in `X4_STAGE_A2_INSTALL_STATE.json`;
8. verifies that X4 MI_03 still uses `usbaudio2`.

No registry FX value is written manually. FX metadata is installed only through the validated Extension INF.

## Verify behavior

`Verify` writes `X4_STAGE_A2_VERIFY_REPORT.json` and reports:

- X4 MI_03 base service;
- APO component presence;
- exact Speaker FX metadata presence under the live X4 `msft_topo` interface;
- whether `X4ApoArm64.dll` is visible in an `audiodg.exe` module list when Windows permits that inspection.

Stage A2 intentionally does not modify the validated APO DLL to add real-time telemetry. Therefore `APOProcess` invocation is not directly instrumented by this package.

After installation, play normal audio through the X4 Speakers endpoint and confirm transparent output before any later DSP/property work.

## Rollback behavior

`Rollback`:

1. removes the exact Stage A2 Extension `oem*.inf` first;
2. removes the exact Stage A2 APO component `oem*.inf` second;
3. rescans/restarts only X4 MI_03;
4. removes only the dedicated Stage A2 test certificate;
5. verifies X4 MI_03 is back on Microsoft `usbaudio2`;
6. writes a rollback JSON record.

After the live test is finished, Windows test-signing and Secure Boot can be restored separately by the user. The Stage A2 script does not change either setting.
